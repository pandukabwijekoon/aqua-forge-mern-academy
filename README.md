# 🌊 Aqua Forge — Premium Swimming Academy Ecosystem

Aqua Forge is an enterprise-grade, high-performance web platform designed for elite swimming academies and private athletic pools. Moving away from standard blueprint aesthetics, it features a custom-built, high-contrast, cinematic dark user interface engineered using the MERN stack.

## 🚀 Core Architecture Features

* **Atomic Session Matrix (Module 3):** Strict server-side concurrency checking engines that implement a 30-minute automated lock on specific pool lanes and coach time blocks instantly upon selection, eliminating double-booking flaws.
* **Automated Transaction OCR (Module 4):** Secure image file streams mapped to a backend cloud storage bucket pipeline paired with text-extraction middleware to verify manual bank deposits against booking payloads.
* **Dual-Channel Notification Gateway:** Direct structural webhook event loops that trigger immediate, server-side automated message dispatches via the Twilio WhatsApp Business API to assigned coach handsets without client-side screen redirection.
* **Coach Verification Control Panel (Module 5):** Specialized, role-guarded enterprise desktop viewport terminals executing atomic state toggles to fully confirm or flush lane allocations safely.
* **Swimmer Telemetry Dashboards:** Live data visualization interfaces that process active telemetry tracking indicators including target volume metrics, logged lane occupancy hours, and specific coach technical remarks.
* **Multi-Profile Relational Architecture:** Allows a single authenticated root user account to flexibly register, manage, and toggle sessions for individual adult profiles or multiple dependent child sub-profiles.

## 🛠️ Tech Stack & Dependencies

* **Frontend:** React.js, Tailwind CSS, Framer Motion, Axios, Chart.js / Recharts
* **Backend:** Node.js, Express.js, JSON Web Tokens (JWT), Bcrypt, Tesseract.js / OCR Helpers
* **Database:** MongoDB Atlas via Mongoose ODM
* **Infrastructure:** Background Worker Queues (BullMQ / Redis), Twilio API Gateway
